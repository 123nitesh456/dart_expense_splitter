Dart Expense Splitter

A beginner-to-intermediate Dart project that tracks shared group expenses and calculates how much each member owes or should receive.

Features

- Add group members with unique names.
- Record expenses with a title, amount, payer, category, and participants.
- Split expenses equally among participants.
- List and filter expenses by member or category.
- Calculate total paid, share owed, and net balance.
- Validate duplicate members, unknown members, invalid amounts, and empty participant lists.
- Demonstrate multiple expenses and multiple payers.

Technologies Used

- Dart programming language
- Classes and objects
- Enums
- Lists, sets, and maps
- Functions and getters
- Input validation and exception handling

How to Run

Install the Dart SDK, open a terminal in the project folder, and run:

dart run main.dart

Alternatively, paste the program into "DartPad" (https://dartpad.dev/) and click Run.

Example

Three members—Asha, Ravi, and Neha—share a dinner costing INR 900. Asha pays the full amount, so Asha should receive INR 600, while Ravi and Neha each owe INR 300.
